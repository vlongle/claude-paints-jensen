# What happened on the physical sheet

The run started with the jacket and worked up to the face. The black marker skipped when clamped rigidly. The operator and agent inspected the page and repeated selected strokes. A marker cap left on during an earlier attempt also produced a convincing motor trace and a blank page.

Green established a separate registration check. A replacement marker can shift sideways when mounted in the same jaws. The grey marker looked almost black on scrap. The operator chose to keep it, and the arm shaded the hair in two batches. The first five grey lines landed roughly 4 mm off target. Orange needed a second pass to make the signature legible. You can see the doubled edges on the physical result.

The portable workflow exposes these decisions. Select a batch, inspect it, then explicitly choose the next index. Keep your own before/after photos. Adjust how the marker sits and teach again if coverage is uneven. The original pressure values were specific to that nib and desk.
